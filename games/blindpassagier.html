FLUG —

Ein Wort kennen alle. Einer nicht.

Ein Handy reicht: Es geht reihum, jeder deckt seinen Pass kurz selbst auf.

Derselbe Code ergibt immer dieselbe Wortreihenfolge. Für ein frisches Spiel einen neuen Code würfeln und laut vorlesen.

Namen (optional)
Spielregeln
  1. Jede Runde bekommen alle dasselbe Geheimwort — nur einer bekommt stattdessen „Blindpassagier“ und sieht bloß die Kategorie.
  2. Der angezeigte Startspieler sagt ein einziges Wort, das zum Geheimwort passt. Dann reihum. Zwei Durchgänge.
  3. Zu offensichtlich, und der Blindpassagier errät das Wort. Zu vage, und ihr verdächtigt euch selbst.
  4. Danach auf drei alle gleichzeitig auf eine Person zeigen.
  5. Punkte: Blindpassagier enttarnt → alle anderen 1 Punkt. Nicht enttarnt → Blindpassagier 2 Punkte. Errät er nach dem Enttarnen das Wort → trotzdem 1 Punkt.
